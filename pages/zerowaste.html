About

ZeroWaste is a smart pantry management application developed as the final project for the Mobile Application Development course at ISEL. Its main goal is to help users keep track of their food inventory, make better use of available ingredients and reduce unnecessary food waste.

The application combines an intuitive Android interface with inventory management, AI-generated recipes, personalized daily tips and statistics. It also introduces gamification and shared state between users to encourage more conscious consumption habits.

Features

  • User authentication and account registration
  • Intuitive dashboard for accessing the main features
  • Product creation and pantry inventory management
  • AI-powered recipe generation based on available ingredients
  • AI-generated daily tips to encourage food waste reduction
  • Statistics and insights into pantry usage
  • User profile and account management
  • Shared application state between users
  • Multimedia support for images, audio, and video
  • Offline functionality
  • Freemium model with free usage and a simulated paid subscription
